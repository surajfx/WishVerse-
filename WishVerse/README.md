# WishVerse — Final 15 Card Modular Version

Home page includes 6 featured cards in a 2x3 grid and all 15 experiences below.

Cards: Proposal, Girlfriend Special, Boyfriend Special, Long Distance Love, Anniversary, Love Letter, Love Confession, Miss You, Sorry, Birthday Surprise, Best Friend Special, Countdown Until We Meet, Good Morning, Good Night, Raksha Bandhan.

Each card has its own folder containing HTML, CSS and JS. Shared Firebase, Cloudinary, saving, link loading and download behavior remains in the shared/common app system.

Before publishing, add/publish firestore.rules in Firebase Console and verify Cloudinary settings.
